# docs/architecture

O padrão arquitetural em si vive em [`ARCHITECTURE-STANDARD.md`](../../ARCHITECTURE-STANDARD.md),
na raiz do PADRAO-AJF. Esta pasta é reservada para diagramas e decisões de arquitetura
específicas de um projeto gerado (ADRs, diagramas de fluxo de dados mais detalhados, etc.) que
não fazem sentido no padrão genérico — adicione conforme o projeto precisar.
