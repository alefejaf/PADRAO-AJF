# docs/backup

A política de backup em si vive em [`BACKUP-STANDARD.md`](../../BACKUP-STANDARD.md), na raiz do
PADRAO-AJF. Esta pasta é reservada para scripts/procedimentos de backup específicos de um
projeto (ex.: um `restore.md` com o passo a passo real já testado naquele projeto) — adicione
conforme necessário.
